# 2B.5 測試預言與斷言合成 (Test Oracle & Assertion Synthesis)

## 📌 核心精神 (Core Concept)
解決軟體測試中的「Oracle 問題」：在已有測試輸入的前提下，自動判斷程式輸出是否正確。本流派聚焦於自動化生成測試斷言（Assertions）、預期輸出與安全不變量，使測試套件具備真正的缺陷偵測能力。

## 🔍 子技術流派 (Sub-Genres)
### NMT/Transformer 斷言生成 (Neural Assertion Generation)
- **簡介**: 以 NMT 或 Transformer 模型從測試前綴（focal method + test prefix）直接生成斷言語句。代表工具：Atlas、TOGA、Tufano BART。

### LLM 驅動斷言合成 (LLM-driven Oracle Synthesis)
- **簡介**: 利用大語言模型透過 Few-shot Prompting、動態反饋迴圈或 RAG 生成高品質測試斷言。代表工具：TOGLL、ChatAssert、AutoOracle、AugmenTest。

### 安全測試預言 (Security Test Oracle)
- **簡介**: 針對 CWE 漏洞模式，生成能偵測安全缺陷的專用斷言與安全不變量。代表工具：SecMutBench、CWEval、SecurityEval。

### 測試補全與上下文推斷 (Test Completion & Context Inference)
- **簡介**: 給定不完整的測試程式碼，自動推斷並補全缺失的斷言或測試邏輯。代表工具：TECO。
