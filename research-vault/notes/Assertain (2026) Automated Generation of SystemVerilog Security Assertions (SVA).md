## Abstract

Automated generation of SystemVerilog Assertions (SVA) is crucial for hardware security verification of RTL designs. Assertain bridges software security vulnerability concepts with hardware RTL specifications by leveraging LLM-driven threat modeling and hardware execution feedback.

Assertain references foundational test oracle classification theories and security invariant concepts to structure its hardware security assertion synthesis pipeline.
