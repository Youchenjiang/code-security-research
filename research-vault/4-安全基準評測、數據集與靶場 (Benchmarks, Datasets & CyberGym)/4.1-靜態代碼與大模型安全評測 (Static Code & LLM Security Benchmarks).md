# 4.1 靜態代碼與大模型安全評測 (Static Code & LLM Security Benchmarks)

## 📌 核心精神 (Core Concept)
專門評估大語言模型（LLM）在代碼生成、靜態漏洞識別、安全合規與安全對齊能力之標準化評測基準、Prompt 注入數據集與自動化評估管線。

## 🔍 子技術流派 (Sub-Genres)
### Code Generation Security Benchmarks (生成代碼安全性評測)
- **簡介**: 評估 AI Copilot/大模型生成之程式碼是否自帶 CWE/CVE 缺陷。代表基準：SecurityEval, CyberSecEval (Meta), CodeSecEval。

### Functional & Security Compliance (功能與安全合規基準)
- **簡介**: 兼顧功能正確性與安全規範之評測。代表基準：CWEval, SecMutBench (CWE變異運算元)。
