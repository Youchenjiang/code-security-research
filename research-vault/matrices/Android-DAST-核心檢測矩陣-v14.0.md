# **Android App 滲透測試——DAST 核心矩陣 (v14.0 論文重構版)**

---

**用途**：專注於 Android 客戶端執行期（Runtime）的動態應用程式安全測試（DAST）矩陣。徹底廢除舊版零散與追補章節，系統性重構為「8 大技術架構域」，並全面融入國際頂尖 DAST 論文（USENIX Security, ACM CCS, NDSS, ICSE 等）之前沿攻擊與驗證方法學。
**適用範圍**：純 Android 客戶端全棧執行期（Android Client Runtime + Native NDK/JNI + IPC/Binder + WebView + Crypto/Keystore + BLE/NFC + Android 13–17 系統行為）。
**版本**：v14.0 論文重構版（共 281 項） | **最後更新**：2026-08-27
